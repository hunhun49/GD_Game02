## 실행

1. Godot 4.7에서 [`gd-game-02/project.godot`](gd-game-02/project.godot)를 엽니다.
2. **F5**로 실행합니다.
3. 시작 위치 왼쪽 위의 서윤에게 다가가 바라본 뒤 E로 대화합니다. 마지막 대사까지 넘기면 위쪽 본관 문으로 들어갈 수 있습니다.

**조작:** WASD / 방향키 이동 · E 상호작용 · Tab 대상 변경 · F2 이동 방식 전환 · R 체크포인트 복귀 · Esc 대화 닫기/일시정지.

기본값은 **8방향 자유 이동 + 4방향 캐릭터 표현**입니다. F2로 4방향 이동과 비교할 수 있습니다. 대각선 이동 속도 보정, 발밑 충돌, 나무·책상 앞뒤 가림, NPC·게시판 대화, 조건부 건물 출입을 구현했습니다.

현재 캐릭터와 배경은 도형으로 만든 임시 그래픽입니다. 진행 상태와 F2로 변경한 이동 모드는 실행 중에만 유지됩니다.

대화 시스템은 데이터 검증, 진행 상태, 독립 UI, 게임 연동과 효과 처리기로 분리되어 있습니다. 여러 콘텐츠 파일과 버전 검증을 지원하며, 완료·취소와 중첩 잠금의 회귀 테스트를 포함합니다.

인게임과 UI는 독립 씬입니다. `scenes/game/ingame.tscn`과 `scenes/ui/game_ui.tscn`을 각각 F6로 실행할 수 있으며, 전체 게임은 F5로 실행합니다. HUD와 일시정지 메뉴도 별도 씬에서 편집합니다.

플레이어와 NPC는 공통 캐릭터 씬을 사용하며 입력·AI, 이동, 표현, 상호작용을 분리했습니다. NPC의 대화와 문·게시판·체크포인트 행동은 독립 클래스로 설정합니다. 캐릭터 상태는 고유 ID로 구역 전환 동안 유지하며, 저장 연동을 위한 JSON 스냅샷을 제공합니다.

관계 그래프와 대화 보상·조건별 대사, 게임 시간과 허기·갈증·피로를 구현했습니다. 운동장 간식대·급수대·벤치와 교실 휴식 침상에서 E로 섭취·휴식·수면을 시험할 수 있습니다. 대화와 일시정지 중에는 시간이 멈춥니다.

운동장 오른쪽 훈련 로봇에게 **J / 패드 B**로 공격할 수 있습니다. 공격에는 별도 스태미나를 사용하며 로봇은 잠시 뒤 반격합니다. E로 로봇을 회복하고, 플레이어가 전투 불능이면 R로 체력을 회복해 체크포인트로 돌아옵니다.
